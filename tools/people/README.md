# Встроенные списки авторов и чтецов

Источник `app/src/main/assets/people/people.bin`: разделы «Авторы»/«Исполнители» сайтов, у которых нет собственного
указателя людей (`search/PeopleIndex.java`), и ключи карточек чтецов fantlab.ru (`search/Narrators.java`).

```
python tools/people/scrape.py ROW...      # обход (продолжается с места остановки) → raw/<ROW>.jsonl, .log
python tools/people/scrape.py --lists     # raw/*.jsonl → lists/<ROW>.authors.tsv, .readers.tsv (имя TAB адрес TAB книг)
python -I tools/people/build_people.py    # lists/*.tsv → people.bin (формат PPL1, описан в начале скрипта)
```

`raw/` (250 МБ) и `lists/` (33 МБ) в git не хранятся; без `lists/` тест `PeopleIndexTest.everyListIsItsTsv`
пропускается. `scrape.py` запускать без `-I` и с `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`: `requests` и `beautifulsoup4` лежат в
пользовательских пакетах. Один процесс на сайт, один запрос за раз, пауза 1,5–3 с, при 429/5xx/заглушке защиты —
ожидание 30·2ⁿ с, после 7 неудач — остановка.

## Что собирается

На человека — имя (самое частое написание), адрес его страницы на сайте и число книг. Число книг — из указателя
сайта, где он есть; иначе — сколько разных книг каталога показывают этого человека в карточке. Числа разных сайтов
несравнимы (А. Байяр: otrub — 9, biblus — 3). В `raw/*.jsonl` есть ещё связи «человек → книга» каждой карточки; в APK
они не идут. Названия книг, рейтинги, просмотры, жанры и годы не собираются: для них нужна страница каждой книги.

## Находки и пределы

- **biblus показывает в карточке каталога только первого автора и первого чтеца**: соавторов и вторых чтецов в
  списке нет («Лорд Хаоса»: в карточке Ник Кроуфорд, на сайте у книги ещё Кристин Кроуфорд). Сверка с otrub (тот же
  каталог, те же адреса `/authors/<slug>.html`): из 20 765 авторов biblus в otrub есть 20 764; в otrub есть ещё 6 225
  авторов и 2 682 чтеца, которых нет в списке biblus. Выборка из 20 их страниц на biblus: книги есть у 4 из 12 авторов
  и 6 из 8 чтецов, у остальных страница пуста. Оценка пропуска: ≈2 000 авторов (≈10 %) и ≈2 000 чтецов (≈25 %).
  Число книг у найденных тоже считает только первые места: Вячеслав Герасимов — 954 в списке, ≈975 на сайте (98
  страниц по 10).
- Как догрузить, если понадобится (решено не делать, 04.11.2026): для каждого человека otrub, которого нет в списке,
  открыть его страницу на biblus; книги — `#books_list > div[id^=book]`, по 10 на страницу, последняя страница — по
  `a[data-page]`, адрес `?p=N`; книг = (последняя − 1)·10 + книги на последней, 0 или 404 — пропустить. Это 8 907
  запросов (≈6,5 ч), только чтецы — 2 682 (≈2 ч).
- Пейджер biblus обещает 13 449 страниц, каталог кончается на 9 415: страница за концом повторяет последнюю, обход
  останавливается на повторе.
- slushat-knigi не показывает чтецов ни в указателе, ни в карточках каталога: их дали бы только страницы книг
  (≈75 000 запросов), поэтому «Исполнителей» у него нет.
- У людей knigoblud нет постоянных адресов (случайный UUID), поэтому в списке — поиск по имени; тёзки сливаются в одну
  строку с суммой книг.
- fantlab отдаёт по букве не больше 250 чтецов, дальше — `&page=2`, `3`…; итог совпадает с числом на сайте (3 965).
- Полнота остальных сайтов не сверялась: в списках все, кого каталог показывает хотя бы в одной карточке; соавторы,
  которых карточка не показывает, туда не попадают (проверено только у biblus). Авторы poleknig не сверены с его
  картой сайта.
